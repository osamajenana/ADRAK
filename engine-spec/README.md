# `engine-spec/` — العقد بين العميل والخادم

المحرّك التكيفي في نبض يعمل في **مكانين**:

- **جهاز الطالب** (`web/src/engine/`, TypeScript) — لأن الطالب يجب أن يحلّ ويُتقن ويفتح المهارة التالية **وهو بدون إنترنت تماماً**.
- **الخادم** (`api/app/Engine/`, PHP) — لأنه المرجع النهائي الذي يعيد الحساب من سجل الأحداث عند المزامنة.

تنفيذان منفصلان لنفس المنطق = خطر تباعد صامت. وتباعد المحرّك لا يظهر كخطأ، بل كطالب يُقال له إنه أتقن مهارة لم يتقنها.

**الحل هنا:** مواصفة واحدة + متجهات اختبار واحدة يشغّلها الطرفان.

```
SPEC.md              المواصفة المعيارية — ست دوال نقية حتمية
reference/index.mjs  التنفيذ المرجعي (JS) — الصيغة القابلة للتنفيذ من SPEC.md
fixtures/            رسم مهارات مصغّر (10 مهارات) تعتمد عليه متجهات التشخيص والمسار
vectors/             52 حالة اختبار — يشغّلها Pest و Vitest معاً
```

## القاعدة الحاكمة

> إذا اختلف تنفيذ عن متجه، **التنفيذ هو الخطأ**.
> لا يُعدَّل متجه أبداً لتمرير اختبار فاشل.

تغيير سلوك المحرّك = تعديل `SPEC.md` ← تعديل `reference/` ← إعادة توليد المتجهات ← تشغيل الطقمين.

```bash
node tools/gen-engine-vectors.mjs     # إعادة التوليد بعد تعديل المواصفة
cd api && ./vendor/bin/pest --filter=EngineSpec
cd web && npm run test -- engine-spec
```

## ما تغطّيه المتجهات

| الملف | الدالة | يغطّي |
|---|---|---|
| `mastery.json` | `masteryScore` | الترجيح بالصعوبة والتلاشي الزمني، وشروط الإتقان الثلاثة كل واحد على حدة، وعتبة مخصّصة |
| `difficulty.json` | `nextDifficulty` | الترقية والتخفيض، السقف والأرضية، والتحويل لمهارة سابقة بعد ٣ أخطاء |
| `diagnostic.json` | البحث الثنائي | ٦ مسارات كاملة خطوة بخطوة، منها الحالة المرجعية: **طالب صف ٧ يُكتشف مستواه الحقيقي (٥) في ٩ أسئلة** |
| `recovery-path.json` | `recoveryPath` | المتطلبات العابرة، تفرّع الماسة، `learning` تُحتسب معلّقة، هدف متقن مسبقاً |
| `elo.json` | `eloUpdate` | معايرة السؤال — لا تقرّر الإتقان أبداً، فقط ترتيب السؤال التالي |
| `review.json` | `nextReviewAt` | المراجعة المتباعدة ٧ ← ٢١ ← ٦٠ يوماً |

## ملاحظة على الدقة العددية

الجمع في IEEE-754 غير تجميعي، و`round()` في PHP تختلف عن `Math.round()` في JS عند الأنصاف السالبة. لذلك تنصّ المواصفة صراحةً على:

- ترتيب الجمع: **من الأقدم إلى الأحدث**
- التقريب: `floor(x * 100 + 0.5) / 100`

هذه ليست تفاصيل تجميلية — بدونها ينحرف الطرفان في الخانة العشرية الثانية، فيتأرجح طالب على حدّ العتبة بين «أتقن» و«لم يُتقن» حسب أي جهاز حسب الدرجة.
